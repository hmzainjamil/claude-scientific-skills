# Security and research-data handling

Scientific files may contain unpublished research, personal or health data, controlled data, credentials, or proprietary analysis. Before enabling an assistant or skill:

- Verify the source, dependencies, permissions, and external services.
- Confirm institutional, funder, data-use, and provider requirements.
- Use synthetic or approved data for initial testing.
- Keep credentials and restricted data out of prompts, logs, issues, and commits.
- Independently verify calculations, code, references, and conclusions.

No scientific skill execution, security audit, or data-handling behavior is verified by this repository guide.

Report vulnerabilities privately through GitHub reporting if enabled, or contact the repository maintainer through a private channel. Do not publish secrets or restricted research data.
